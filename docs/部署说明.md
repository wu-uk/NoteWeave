# NoteWeave 演示部署说明

本文档面向当前演示 demo，不追求多人生产级架构。目标部署地址：

```text
http://wu-uk.com/noteweave/
```

Cloudflare Edge Certificate 变为 Active 前，不强制 HTTP 跳 HTTPS。

## 1. 推荐部署形态

```text
Nginx
  /noteweave/              -> frontend/dist 静态文件
  /noteweave/api/*         -> 127.0.0.1:8000/api/*
  /noteweave/health        -> 127.0.0.1:8000/health

systemd
  noteweave-backend.service -> FastAPI + SQLite + 本地 uploads
```

## 2. 前端构建

```bash
cd /root/project/NoteWeave/frontend
npm install
npm run build:noteweave
```

部署静态文件：

```bash
mkdir -p /var/www/wu-uk.com/html/noteweave
rsync -av --delete dist/ /var/www/wu-uk.com/html/noteweave/
```

## 3. 后端运行

演示环境继续使用 SQLite 和本地上传目录：

```bash
mkdir -p /var/lib/noteweave/uploads
cd /root/project/NoteWeave/backend
env UV_CACHE_DIR=/root/project/NoteWeave/.uv-cache ../.tools/uv/bin/uv pip install -e ".[dev]"
```

建议 systemd 环境变量：

```text
NOTEWEAVE_ENV=demo
NOTEWEAVE_DATABASE_PATH=/var/lib/noteweave/noteweave.sqlite3
NOTEWEAVE_FILE_STORAGE_DIR=/var/lib/noteweave/uploads
NOTEWEAVE_ENABLE_AI=true
NOTEWEAVE_MODEL_BASE_URL=你的模型 API Base URL
NOTEWEAVE_MODEL_API_KEY=你的模型 API Key
NOTEWEAVE_CHAT_MODEL=你的模型名
```

后端监听本机：

```bash
cd /root/project/NoteWeave/backend
env NOTEWEAVE_ENV=demo \
  NOTEWEAVE_DATABASE_PATH=/var/lib/noteweave/noteweave.sqlite3 \
  NOTEWEAVE_FILE_STORAGE_DIR=/var/lib/noteweave/uploads \
  UV_CACHE_DIR=/root/project/NoteWeave/.uv-cache \
  ../.tools/uv/bin/uv run --no-sync uvicorn noteweave.api.app:app --host 127.0.0.1 --port 8000
```

## 4. Nginx 配置片段

加入 `/etc/nginx/sites-available/wu-uk.com` 对应 server block：

```nginx
location = /noteweave {
    return 301 /noteweave/;
}

location /noteweave/api/ {
    proxy_pass http://127.0.0.1:8000/api/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}

location = /noteweave/health {
    proxy_pass http://127.0.0.1:8000/health;
    proxy_set_header Host $host;
}

location /noteweave/ {
    alias /var/www/wu-uk.com/html/noteweave/;
    try_files $uri $uri/ /noteweave/index.html;
}
```

检查并重载：

```bash
nginx -t
systemctl reload nginx
```

## 6. 当前限制

1. 新 Vue 前端已覆盖登录、课程、知识树、笔记、错题和检索基础流程。
2. 旧前端中的评论、点赞、收藏、成员管理、AI 结果采纳等高级交互还未完整迁移到新前端。
3. 演示环境使用 SQLite，不适合多人并发或长期正式运营。
4. 服务器 SSH 安全加固仍应尽快处理，至少禁用 root 密码登录。
