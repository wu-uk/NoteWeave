## 4. 架构约束审计

| 约束 | 结论 | 证据 |
| --- | --- | --- |
| Vue 3 + Vite + TypeScript | 已满足 | `frontend/package.json`、`vite.config.ts`、`vue-tsc` 验证。 |
| FastAPI + SQLite + uv | 已满足 | 后端 `pyproject.toml`、`Database`、验证命令均使用 uv。 |
| 只通过远程 API 调用模型 | 已满足 | `AIAssistService` 使用 OpenAI-compatible `/chat/completions`；真实阿里云 API 测试通过。 |
| 不引入 OCR、本地模型、GPU、向量库重依赖 | 已满足 | PDF 仅 `pypdf` 文本抽取；检索使用 SQLite `search_chunks`。 |
| MoDora 流程借鉴：解析 -> 结构化 -> 检索 -> 问答 | 已满足 | `/api/notes/import`、`ensure_ai_course`/`ensure_ai_node`、`search_chunks`、`/api/notes/ask` 形成闭环。 |
| 部署到 `/noteweave/` | 已满足 | Nginx/systemd 部署在线，线上 health 正常。 |

## 5. 非本期和后续项

以下在文档中属于 P1 或后续演进，不作为当前 MVP 完成条件：

1. 图片附件插入笔记正文。
2. 更完整的管理员数据维护/AI 配置 UI。
3. 彻底移除旧课程兼容 API。
4. 托管向量服务或 embedding 检索。
5. OCR、复杂 PDF 版面解析、本地模型/GPU。

结论：当前 NoteWeave note-first MVP 的 P0 功能、架构约束和线上部署状态均有当前证据证明完成。
