# NoteWeave 需求文档

## 1. 产品定位

NoteWeave 是一个以笔记为核心的学习辅助 Demo。用户不需要先创建课程、加入课程或维护复杂成员角色，只需要持续添加、上传、共享和讨论笔记；系统通过 AI 解析笔记内容，自动判断它属于哪个课程、知识点或主题，并围绕笔记提供检索和问答能力。

当前阶段目标是做出可演示、可部署、逻辑清晰的原型，而不是完整多人教学平台。

## 2. 设计原则

1. 笔记优先：所有主要入口围绕“添加笔记、查看笔记、共享笔记、问笔记”展开。
2. AI 自动归类：课程和知识点由 AI 根据笔记内容生成或匹配，前端不提供手动新建课程、加入课程功能。
3. 轻量协作：只保留普通用户和管理员两类系统角色。普通用户可写笔记、共享、评论、点赞；管理员负责系统配置和后续数据维护。
4. 借鉴 MoDora：学习 MoDora 的“文档解析 -> 结构化树 -> 检索上下文 -> 问答生成”链路，但不照搬 OCR、本地模型、GPU、复杂 PDF 处理等重依赖。
5. API 模型访问：AI 只通过远程模型 API 接入；没有配置模型时必须保留 fallback，保证 demo 可运行。

## 3. 用户角色

| 角色 | 说明 | 权限 |
| --- | --- | --- |
| 普通用户 | Demo 的主要使用者 | 注册登录、添加/编辑/删除自己的笔记、共享笔记、评论、点赞、提问 |
| 管理员 | 系统级维护者 | 普通用户全部能力，外加后续用户管理、AI 配置、数据维护 |

不再设置课程维护者、教师、助教、学生等课程级角色。

## 4. 核心闭环

```text
注册/登录 -> 添加或上传笔记 -> AI 解析与自动课程归类 -> 笔记流展示
        -> 共享/评论/点赞 -> 检索相关片段 -> 基于笔记问答
```

## 5. MVP 功能范围

### 5.1 账号

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-001 | 用户可以注册、登录、退出。 | P0 |
| FR-002 | 系统只区分普通用户和管理员。 | P0 |
| FR-003 | 未登录用户只能查看 landing，不能使用笔记工作台。 | P0 |

### 5.2 笔记

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-010 | 普通用户可以添加文本笔记。 | P0 |
| FR-011 | 普通用户可以编辑、删除自己的笔记。 | P0 |
| FR-012 | 笔记支持个人和共享两种可见性。 | P0 |
| FR-013 | 普通用户可以将个人笔记发布为共享笔记。 | P0 |
| FR-014 | 笔记应保存标题、正文、摘要、标签、作者、创建时间、更新时间。 | P0 |
| FR-015 | 支持导入 PDF、Word `.docx`、Markdown 文件，并把解析文本作为笔记进入 AI 归类流程。 | P0 |
| FR-016 | 后续支持图片附件插入笔记正文。 | P1 |

### 5.3 AI 解析与自动归类

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-020 | 用户保存新笔记时，系统调用 AI 判断课程分类和知识点。 | P0 |
| FR-021 | AI 返回课程名、知识点名、摘要和标签。 | P0 |
| FR-022 | 课程分类作为内部组织结构展示，不要求用户手动创建或加入。 | P0 |
| FR-023 | AI 不可用时，系统使用关键词 fallback 自动生成摘要、标签和分类。 | P0 |
| FR-024 | 用户可以对已有笔记单独生成摘要或标签，并决定是否采纳。 | P1 |

### 5.4 共享互动

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-030 | 普通用户可以浏览自己可见的笔记。 | P0 |
| FR-031 | 普通用户可以浏览共享笔记。 | P0 |
| FR-032 | 普通用户可以对笔记点赞。 | P0 |
| FR-033 | 普通用户可以评论笔记。 | P0 |
| FR-034 | 评论和点赞应影响笔记流的可见信息。 | P1 |

### 5.5 检索与问答

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-040 | 系统为笔记生成可检索片段。 | P0 |
| FR-041 | 用户可以按关键词筛选或搜索笔记。 | P0 |
| FR-042 | 用户可以向系统提问，系统先检索相关笔记片段，再生成回答。 | P0 |
| FR-043 | 问答结果应展示引用/上下文片段，便于用户判断答案来源。 | P0 |
| FR-044 | 没有远程模型时，系统应返回检索片段摘要而不是失败。 | P0 |

## 6. 非本期范围

1. 手动创建课程、加入课程、邀请码、课程成员管理。
2. 教师/助教/课程维护者等多层课程角色。
3. 实时多人协同编辑。
4. 商业化公开社区。
5. OCR、PDF 版面视觉解析、本地模型部署、GPU 调度。
6. 复杂向量数据库和大规模检索评测。

## 7. 验收标准

1. 用户可以打开 landing，并进入 Vue 工作台。
2. 用户注册/登录后，可以添加一条笔记。
3. 用户可以导入 PDF、Word `.docx`、Markdown 文件，系统抽取文本并创建笔记。
4. 保存或导入新笔记后，系统自动生成课程分类、知识点、摘要和标签。
5. 前端不出现“新建课程”“加入课程”“课程成员角色管理”等主功能入口。
6. 用户可以共享笔记、点赞笔记、评论笔记。
7. 用户可以向笔记提问，系统返回答案和上下文片段。
8. 未配置远程模型时，以上流程仍可通过 fallback 完成。
